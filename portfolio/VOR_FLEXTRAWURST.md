### 5. Sports-betting prevention system / tipping game

- **Tried:** An "interactive prevention system for live betting interfaces". The blueprint states its purpose as not keeping people from playing but making it tangible why rational decisions do not stay stable in certain structures. Core rules: no real money, no advertising, no endless loop, clear exit points. Modules: time, budget, round, selection, combination, virtual league, live, attention, cash-out. The state machine has the states INIT, SELECT, LOCKED, LIVE, RESOLVE.
- **Why:** The blueprint: "Prevention arises from structure, not from prohibitions." Daniel's own why: **(Daniel adds)**
- **What is inside:** In `fruehe-ai-projekte/sportwetten-tippspiel/`: `projekt blueprint.md`, `roadmap.md`, `statemaschiene.md` and `sportbetsystemgame.html` ("Liga & Spiel – B.1 FINAL (FIXED)": tipping menu, table, start live, next matchday, active bets).
- **State and limit:** The documents give different round lengths: the blueprint 3 minutes, roadmap and state machine 90 seconds. The HTML file is a runnable prototype without a server and without storage. The roadmap has three phases; which of them the file reaches was not checked.
