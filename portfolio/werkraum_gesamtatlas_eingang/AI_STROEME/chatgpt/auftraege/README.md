# chatgpt / auftraege

Von Daniel an diesen Strom gerichtete Auftraege oder Aufgabenbeschreibungen, die hier archiviert werden sollen (z.B. laengere schriftliche Briefings, die nicht nur im Chat verlaufen sollen).

Dieser Ordner gehoert zum Strom **chatgpt**. Andere Stroeme legen hier nichts ab --
jeder Strom hat seinen eigenen Satz dieser sechs Kategorien unter `AI_STROEME/<strom>/`.

Siehe `../../README.md` fuer die vollstaendige Konvention.
