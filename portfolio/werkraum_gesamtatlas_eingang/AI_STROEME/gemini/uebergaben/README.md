# gemini / uebergaben

Bewusst an einen anderen Strom oder an Daniel uebergebene Texte -- das Gegenstueck zu AI_UEBERGABEN/<strom> im alten Schema, jetzt unter der eigenen Stromkennung.

Dieser Ordner gehoert zum Strom **gemini**. Andere Stroeme legen hier nichts ab --
jeder Strom hat seinen eigenen Satz dieser sechs Kategorien unter `AI_STROEME/<strom>/`.

Siehe `../../README.md` fuer die vollstaendige Konvention.
