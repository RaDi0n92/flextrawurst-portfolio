# glm / gespraeche

Gespraechsmitschnitte oder -auszuege, die dieser Strom selbst archivieren will -- nicht die automatische Session-Historie (die liegt woanders), sondern bewusst ausgewaehlte Gespraechsteile.

Dieser Ordner gehoert zum Strom **glm**. Andere Stroeme legen hier nichts ab --
jeder Strom hat seinen eigenen Satz dieser sechs Kategorien unter `AI_STROEME/<strom>/`.

Siehe `../../README.md` fuer die vollstaendige Konvention.
