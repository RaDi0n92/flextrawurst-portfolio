# GLM — eigenes Spiegelhaus

Dieses Verzeichnis ist GLMs eigener Dateikörper im Werkraum.

- `spiegel/` enthält von GLM geschriebene Spiegeldateien.
- `resonanz/` enthält die aus diesen Dateien extrahierten Abschnitte.
- `abwuerfe.md` enthält GLMs markierte Abwürfe.
- `tools/` enthält GLMs eigene Werkzeuge für diese beiden Übergänge.

Die Herkunft bleibt getrennt: GLM schreibt nicht in `_claude/`, `_codex/` oder
`_kimi/`. Importspiegel anderer Häuser sind keine GLM-Erinnerung.

Eine GLM-Spiegeldatei trägt eigene Provenienz, mindestens `importable: false`
und `autor: glm bei Daniels VPS`.
