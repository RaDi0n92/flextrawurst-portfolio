# Neutraler MCP-Arbeitskörper

Dieser Körper ist der globale Fallback für MCP-, GPT- und AI-Strom-Arbeit, die keinem konkreten Projekt ausdrücklich zugeordnet wurde.

## Routingregel

- Konkretes Projekt im Auftrag genannt: Belege, Sitzungen und Projektionen dorthin routen.
- Kein konkretes Projekt genannt: hier arbeiten.
- Niemals aus einer früheren Sitzung still ein fremdes Projekt als Standard übernehmen.

## Validierungsregel

Kanonische Validierungsbelege tragen mindestens einen UTC-Zeitstempel im Dateinamen: `YYYYMMDDTHHMMSSZ`. Wiederholte Prüfungen erzeugen neue Dateien. `LATEST` ist nur ein Zeiger und niemals der historische Beleg selbst.
