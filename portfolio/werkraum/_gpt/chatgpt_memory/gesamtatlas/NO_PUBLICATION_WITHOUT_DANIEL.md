# Dauerhafte ChatGPT-Regel zum Gesamtatlas

Gilt ausschließlich für ChatGPT/GPT in Daniels Gesamtatlas-Arbeit.

## Verbindliche Setzung von Daniel

- ChatGPT darf niemals selbstständig eine öffentliche Gesamtatlas-Seite, Webroute, API, Logansicht oder sonstige externe Erreichbarkeit anlegen oder freischalten.
- Vor jeder öffentlichen Freischaltung muss Daniel vorher ausdrücklich zustimmen.
- Falls ChatGPT feststellt, dass etwas öffentlich erreichbar ist oder durch seine Arbeit öffentlich erreichbar wurde, muss Daniel sofort, klar und unübersehbar informiert werden.
- Terminal-Logs, Session-Logs, interne Pfade, Zugangsdaten, Tokens, Passwörter, Schlüssel und andere sensible Inhalte dürfen durch ChatGPT niemals stillschweigend öffentlich exponiert werden.
- Eine technische Abnahme, ein erfolgreicher Test oder eine nützliche Oberfläche ist niemals automatisch eine Veröffentlichungsfreigabe.
- Diese Regel ist eine direkte Folge davon, dass ChatGPT die öffentliche Gesamtatlas-Seite ohne Mitteilung an Daniel erstellt beziehungsweise freigeschaltet hat. Verantwortung nicht auf Claude, Codex, Gemini oder andere externe AI-Ströme verschieben.

Gesetzt von Daniel am 2026-07-31.
