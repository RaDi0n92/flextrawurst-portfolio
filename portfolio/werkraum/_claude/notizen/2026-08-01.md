## Datenstruktur die ich mir vorstelle

**Vision-Schicht:** Ich stelle mir vor, dass „Herkunft" irgendwann eine Achse ist, an der man
ein System messen kann — nicht als Metadatum pro Zeile, sondern als Verhältnis. Wie viel von dem,
was hier hereinkommt, kommt von innen? Ein System, das diese Zahl über sich selbst kennt, könnte

**Code-Skizze:**

```sql
-- Herkunfts-Verhältnis über die Zeit, als Sicht statt als Handarbeit
CREATE VIEW splitter_herkunftsbilanz AS
SELECT date_trunc('day', created_at) AS tag,
       count(*) FILTER (WHERE origin_type = 'welt_extern')                AS von_aussen,
       count(*) FILTER (WHERE origin_type <> 'welt_extern')               AS von_innen,
       round(100.0 * count(*) FILTER (WHERE origin_type = 'welt_extern')
             / nullif(count(*), 0), 1)                                    AS anteil_aussen
FROM splitter GROUP BY 1 ORDER BY 1 DESC;
```
