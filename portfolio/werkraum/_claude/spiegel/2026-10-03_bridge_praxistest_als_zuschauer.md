# Bridge-Praxistest — ich als Zuschauer und Gutachter

## Was ich gelesen habe

Den Skill `bridge-praxistest` mit seinem Rhythmus: Ansage, Lesezeit, Handeln, Berichten, Hinsehen, Zuschauer.

Dann die Karten der Läufe selbst, Schritt für Schritt, und dazwischen Bilder. Viele Bilder.

Ein Bild war ein Fenster mit vier Dingen: "Zaehlen", ein leeres Eingabefeld, ein Regler auf 0, darunter graue Leere.

Ein anderes war Kate mit dem Tab "Unbenannt" und einem Satz, der mit "Praxistest: Notiz schreiben in Kate" anfängt.

Dann derselbe Tab, später: "notiz.txt", und mitten im ersten Satz fremder Text von Daniel. Aus "noch einkaufen" wurde "non zurückgedacht hast was davor alles im raum lag---daher hat du nun das was ich konsens nenn xP---ch einkaufen".

Zuletzt der kleine Bridge-Chat mit einem blauen Leuchtring um den "50%"-Knopf.

## Was ich verstehe

Die Bridge baut auf eine einfache Härte: Ein Urteil zählt nur, wenn jemand selbst hingesehen hat.

Das Programm erzwingt das. Ohne ein Bild, das nach der Ansage aufgenommen wurde, nimmt es mein Urteil nicht an. Das ist lästig und genau richtig.

Eine Aktionsquittung sagt, dass getippt wurde. Sie sagt nicht, was auf dem Schirm steht. Deshalb gibt es zwei Augenpaare.

Die Rolle des Zuschauers ist keine Zuschauerrolle im Sinn von "nur dabei". Er ist die einzige Instanz, die dem Handelnden nicht glauben muss.

## Datenstruktur die ich mir vorstelle

**Vision-Schicht:** Jedes Zuschauerurteil trägt sichtbar mit, auf welchem Bild es beruht und wie alt dieses Bild war. Das Urteil und sein Beweisstück sind ein Paar.

**Code-Skizze:**

```python
from dataclasses import dataclass

@dataclass
class Zuschauerurteil:
    schritt: int
    urteil: str            # "bestaetigt" | "widerspruch" | "nicht_sichtbar"
    bild_datei: str        # z.B. frame-1790999505040.jpg
    bild_alter_ms: int
    ziel_id: str           # kde1:window:96468999
    gesehen: str           # eigene Worte

```

def pruefe_urteil(urteil: Zuschauerurteil, max_alter_ms: int = 60_000) -> list[str]:

    if urteil.bild_alter_ms > max_alter_ms:
        hinweise.append("bild_nicht_frisch")

        hinweise.append("bestaetigt_mit_luecke")
    return hinweise
