## Was zusammenhängt und wie

ChatGPT äußere Turn-Sections liefern Rollen und Reihenfolge. Der manuelle Observer hält sichtbar gewordene Turns fest. Die Popup-Projektion erzeugt daraus Markdown, Text, CSV, JSON oder die gemeinsame Fünffarben-PDF. Evidence-Bericht und Session-Notiz halten die Beleggrenze fest.

## Was konzeptionell darin steht

Der Export ist kein heimlicher Zugriff auf den Provider, sondern eine bewusst gestartete Projektion eines sichtbar gemachten Gesprächskörpers. Vollständigkeit ist hier ein beobachtbarer Zustand, keine Annahme.

## Datenstruktur die ich mir vorstelle

**Vision-Schicht:** Ein Gespräch ist eine geordnete Spur von sichtbar gewordenen Stimmen. Jede Stimme trägt Herkunft, Rolle und den Umstand, dass sie wirklich gesehen wurde; die Lücke zwischen gesehen und vorhanden bleibt sichtbar.

**Code-Skizze:**

```ts
type Role = 'user' | 'assistant';
interface CapturedTurn {
  role: Role;
  text: string;
  visible: true;
  sourceSelector: string;
  order: number;
  sequence: number;
}
interface ExtractionMeta {
  mode: 'visible-dom-manual-accumulation';
  autoScrolled: false;
  networkFetched: false;
  completeness: 'only-turns-that-were-visible-after-capture-start';
}
```

## Wenn wir das bauen

**Vision-Schicht:** Die Replika soll nicht behaupten, den ganzen Provider zu besitzen. Sie soll die sichtbare, gemeinsam geprüfte Strecke eines Gesprächs tragen und die unsichtbare Strecke als Grenze respektieren.

**Code-Skizze:**

```js
function beginManualCapture() {
  captureActive = true;
  observer.observe(document.body, { childList: true, subtree: true, characterData: true });
}

function readAgain() {
  const turns = captureVisibleMessages();
  return turns.sort((a, b) => a.order - b.order || a.sequence - b.sequence);
}
```
