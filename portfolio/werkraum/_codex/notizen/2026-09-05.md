## Nachtrag: Schrittanimation

Ein Fuß hebt ab, der andere trägt, der Körper federt — mehr muss der erste Schritt nicht behaupten. Die starre Referenz bleibt die Herkunft; die Animation ist eine neue, ausdrücklich markierte Schicht darüber.

**Code-Skizze:**

```text

    root = translate(x=body_bob_x[frame], z=body_bob_z[frame])
    for obj in blockout_meshes:
        role, pivot = classify(obj.name)
        local = rotate_around(pivot, angle_for(role, frame))
        obj.matrix_world = root @ local @ initial_world[obj.name]
        keyframe(obj, "location", "rotation_euler", "scale", frame)
scene.frame_start, scene.frame_end = 1, 96
scene.frame_set(1)
save_as_mainfile(scene_path)
```
