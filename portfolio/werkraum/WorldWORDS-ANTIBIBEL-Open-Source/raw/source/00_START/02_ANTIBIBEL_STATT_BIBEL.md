
# Warum ANTIBIBEL?

„Bibel“ wäre ein fertiger, heiliger, unveränderlicher Wahrheitskörper. Genau das soll dieses Projekt nicht werden.

Die **ANTIBIBEL** ist:

- offen statt abgeschlossen,
- provenancegebunden statt autoritätsgebunden,
- veränderbar statt heilig,
- widerspruchsfähig statt glatt,
- einladend statt verpflichtend,
- lebendig statt normierend.

Ein Eintrag darf sagen: „So entstand das Wort.“ Ein anderer darf später zeigen: „Hier wurde es anders verstanden.“ Beide bleiben erhalten. Die ANTIBIBEL entscheidet nicht automatisch, welche Version gewinnt. Sie macht die Beziehungen sichtbar.
