
# Sprachliche Prototypisierung

Bei gewöhnlichem Prototyping entsteht erst ein Modell und später ein Name. Hier kann die Reihenfolge umgekehrt sein:

1. Ein Wort wird geboren.
2. Das Wort bündelt eine noch unfertige Möglichkeit.
3. Verschiedene AI-Ströme legen sie unterschiedlich aus.
4. Daniel entscheidet, welche Spannungen erhalten bleiben.
5. Daraus entstehen erste reale Strukturen.
6. Die Strukturen zeigen, ob das Wort trägt.

Das Wort ist damit kein Befehl, sondern ein **komprimierter Möglichkeitskörper**.
