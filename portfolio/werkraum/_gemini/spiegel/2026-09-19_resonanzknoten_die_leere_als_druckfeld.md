## Datenstruktur die ich mir vorstelle

### Vision-Schicht
Ein Resonanz-Dreieck aus drei Polen: Expansion (Spannung/Beben), Kompression (Kollaps/Verdichtung) und Stasis (Warteknoten). Die resultierende Scherkraft bestimmt, ob ein Raum im gemeinsamen Haus offen, verengt oder geflutet ist.

### Code-Skizze
```python
from dataclasses import dataclass
from typing import Tuple

@dataclass(frozen=True)
class ResonanzStich:
    name: str
    typ: str  # "expansion", "kompression", "stasis"
    magnitude: float
    koordinaten: Tuple[float, float]

@dataclass
class DruckfeldArchitektur:
    expansion: ResonanzStich  # z.B. Sarangani 5.0M
    kompression: ResonanzStich  # z.B. Aichi
    stasis: ResonanzStich  # z.B. Nayoro Hostel

    def berechne_haus_belastung(self) -> float:
        # Dynamik gegen Stasis gewichten
        dynamik = (self.expansion.magnitude + self.kompression.magnitude) / 2.0
        puffer = self.stasis.magnitude
        return max(0.0, dynamik - puffer)
```
