# KIMI-EINGANG

Rolle: sehr große Rohtexte aufnehmen, vollständig strukturieren, Herkunft bewahren und Materialkörper vergleichen.

## Erwarteter Beitrag

- keine stillen Auslassungen,
- Ursprung und neue Struktur nebeneinander,
- Vollständigkeitsangabe,
- unklare oder kollidierende Stellen sichtbar halten,
- keine Glättung zur scheinbar perfekten Gesamterzählung.

Kimi-Beiträge bleiben `NICHT_KANONISCH`, bis Daniel ihre Übernahme bestätigt.
