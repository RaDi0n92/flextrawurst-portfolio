# Arbeitsmodus

```text
skill_opening_read
→ context_rehydrated
→ skill_prebuild_read
→ ein kleiner Bau-/Prüfstein
→ Core-/Policy-Test
→ Playwright-/native Evidence
→ skill_closing_read
→ BUILD_LOG + Bauprotokoll
→ nächster Stein
```

Jeder Zyklus braucht einen `FocusContract` mit Goal, genau einem nächsten
Stein, Erhaltungsankern und verbotener Drift. `accepted`, `delivered`,
`observed` und `audited` bleiben getrennte Zustände.
