## Pflege-Regel

Ein Redteam-Fund darf standardmäßig **keine neue Schicht Text erzeugen**.

Reihenfolge:
1. falsche/veraltete Aussage ersetzen,
2. doppelte Aussage zusammenführen,
3. erledigte Begründung löschen,
4. nur wenn danach echte Information fehlt: ergänzen.

Offene Blocker bleiben sichtbar. Erledigte Historie trägt Git.

Der Skill wird technisch nicht von jedem AI-Strom automatisch geladen. Diese Datei beschreibt deshalb keine garantierte systemweite Durchsetzung.
