# ChatGPT_Work

Dieser Ordner ist der eigene Körper der bisherigen ChatGPT-Work-Session.

1. `00_CHATGPT_WORK_SESSIONKOERPER.md` zuerst lesen: für Menschen und andere Agenten.
2. `01_CHATGPT_WORK_SESSIONINDEX.json` danach lesen: maschinenlesbare Verweise auf dieselben echten Dateien, Objekte, Kanten, Container und Spuren.

Der JSON-Index kopiert keinen Planerzustand. `data/current.json` bleibt die kanonische gemeinsame Wahrheit. Wenn eine referenzierte ID fehlt, ist das ein zu reparierender Widerspruch, keine Einladung, eine zweite Wahrheit hier zu erfinden.
