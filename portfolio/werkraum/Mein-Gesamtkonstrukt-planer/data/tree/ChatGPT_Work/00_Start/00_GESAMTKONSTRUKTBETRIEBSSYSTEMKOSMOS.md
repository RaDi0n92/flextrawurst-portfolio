# Gesamtkonstruktbetriebssystemkosmos

Arbeitsname für das entstehende System.

Es ist kein Planer mit Ansichten, sondern ein Betriebssystem für unterschiedliche reale Arbeitskörper:

- Quellen, Dateien und Orte
- Ideen, Skizzen und Referenzen
- Abläufe, Automationen und Live-Systeme
- Bilder, Vektoren, Code und Versionen
- Menschen, Agenten und ihre überprüfbaren Beiträge

## Aufbauprinzip

Ein Bereich existiert nur dann als Werkstatt, wenn er:

1. einen eigenen Eingang hat;
2. eine eigene produktive Handlung ermöglicht;
3. ein eigenes Ergebnis erzeugt;
4. dieses Ergebnis mit Quelle, Objekt, Kante oder Ereignis zurückgibt.

## Aktueller Bauzug

Die 17 Werkstätten werden nacheinander nicht als Designvarianten, sondern als eigene Arbeitssysteme aufgebaut. Ihr gemeinsamer Bestand wird nicht verdoppelt: Jede Werkstatt verändert oder erzeugt bewusst adressierbare Körper mit Herkunft.
