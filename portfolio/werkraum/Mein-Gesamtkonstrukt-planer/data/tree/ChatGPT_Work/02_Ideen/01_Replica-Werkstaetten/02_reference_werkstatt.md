# Referenzwand · PureRef

## Status
Bauidee aus der Live-Gegenprobe der bisherigen Replica. Sie ist kein Fertigstellungsclaim.

## Eigener Eingang
- Bilder
- Dateien
- Links

## Eigene Kernhandlungen
- Import
- Verschieben
- Skalieren
- Zuschnitt
- Sperren
- Board speichern

## Ergebnis und Rückweg
Referenzboard mit Herkunft

## Sichtbare Ebenen
- Bilder
- Markierungen
- Quellen

## Erster vollständiger Bauzug
Ein neuer Referenzwand-Arbeitskörper wird bewusst am gewählten Kontext angelegt; mindestens eine Kernhandlung erzeugt ein Ergebnis mit Datei/Objekt/Kante/Ereignis und überlebt Reload.

## Abhängigkeit
Arbeitsraum → gewählter Körper → Werkstatt. Kein stiller Fallback auf Mein Gesamtkonstrukt.
