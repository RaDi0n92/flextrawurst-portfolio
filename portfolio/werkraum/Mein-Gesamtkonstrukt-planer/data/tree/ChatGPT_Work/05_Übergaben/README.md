# Übergaben

Eine Übergabe zeigt den realen Stand für Menschen und andere Agenten: Gegenstand, Orte/IDs, erledigte Nutzerhandlung, Beleg, bekannte Grenze und nächste konkrete Handlung. Sie ersetzt weder Originale noch Ereignisse.

## Einstieg

- `Codex/00_Codex_WORK_SESSIONKOERPER.md` — eigener Arbeitskörper der bisherigen Codex-Session: reale VPS-Pfade, Änderungen, Container, Browserbelege und offene Grenzen. Er ist kein globales Start-/Canvas-/Netz-/Plan-/Zeitspur-System.
