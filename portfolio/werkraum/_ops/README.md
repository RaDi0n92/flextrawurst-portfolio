# _ops

Status: aktive Ordnungszone

Betriebs- und Ordnungsnachweise für den VPS.

Vorgesehene Unterteilung:

- `inventories/`
- `reports/`
- `migrationen/`
- `hashlisten/`
- `wiederherstellung/`

Hier liegen keine produktiven Live-Daten. Dieser Bereich dokumentiert, was geprüft, verschoben, ersetzt, gesichert und zurückgelesen wurde.

Jede reale Migration braucht mindestens einen Vorher-Bestand, eine Aktionsliste, einen Nachher-Bestand und einen Testnachweis.
