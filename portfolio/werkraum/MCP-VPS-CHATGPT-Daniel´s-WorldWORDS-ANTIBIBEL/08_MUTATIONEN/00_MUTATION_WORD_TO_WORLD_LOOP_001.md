# MUTATION_WORD_TO_WORLD_LOOP_001

## Vorschlag

Jedes neue WorldWORD darf einen nachvollziehbaren Wachstumsweg durchlaufen:

`Fundstelle → Rohkörper → Deutungen → Grenzen → Beziehungen → reale Verkörperung → Wirkungsbeobachtung → spätere Mutation`

## Benötigte Organe

- Sammelbecken,
- Wortkörper,
- Gesprächsquellen,
- Herkunftsregister,
- Bedeutungsgraph,
- Zeitstrom,
- Status- und Wahrheitsklassen,
- Verweise auf reale Verkörperungen,
- Korrektur- und Widerspruchskörper.

## Abnahmekriterium

Ein Wort gilt nicht schon als „verkörpert“, weil eine Beschreibung existiert. Mindestens ein außerhalb des reinen Eintrags liegender Körper muss real vorhanden und rückgelesen sein: beispielsweise Rolle, Vertrag, Datei, Oberfläche, Ablauf oder Feature.
