# Weltbetriebssystem Ring 4 — Origin Import Gate + Activation Firewall + Read-only Console Model + OS Convergence

## Was Ring 4 ist

Ring 4 verbindet erstmals Herkunft, Slot-System, Aktivierungsverbot, Read-only-Konsole und OS-Spine zu einem kohärenten Konvergenzring. Er bereitet den ersten Realitätsanschluss vor, ohne ihn zu vollziehen.

## Was Ring 4 baut

- **Import Candidate Model**: Strukturtypen für Forum-/Flarum-Herkunft ohne echten Dateiimport
- **Account-to-Slot Mapping**: Herkunfts-Accounts werden kanonischen Slots zugeordnet — kein Einzug
- **Import Dry Run**: Prüft, was ein Import täte, schreibt aber nichts
- **Import Provenance Preview**: Markiert importierte Posts als `flarum_import_candidate`, nicht als Live-Handlungen
- **Activation Firewall**: Berichtet, warum alle Slots blockiert bleiben
- **OS Spine Import Extension**: Erweitert den Spine mit Import-Gate ohne Mutation
- **Read-only Console Model**: Datenmodell für eine spätere Konsole — kein Renderer, keine UI
- **Console Export**: Deterministischer JSON-Export des Konsolenmodells
- **OS Convergence Report**: Berichtet, was bereit ist und was noch fehlt

## Verbindliche Schutzformeln

- Flarum-Import ≠ Aktivierung
- Forum-Account ≠ eingezogenes Wesen
- ImportedPost ≠ Live-Handlung
- OriginMapping ≠ Bewohnerprofil
- ReadOnlyConsole ≠ UI
- ConsoleModel ≠ Renderer
- ActivationFirewall blockiert Einzug
- Slots bleiben Slots

## Was Ring 4 nicht baut

- Keinen echten Dateiimport aus ZIP, HTML oder Forum-Export
- Kein HTML-Parsing
- Keine UI, kein Canvas, kein DOM, kein CSS
- Keinen Renderer
- Keine AI-Anbindung
- Kein Postgres
- Keinen Scheduler
- Keinen Daemon
- Keine Aktivierung
- Keinen Einzug
- Keinen occupied-Status

## Leitanker

Flextrawurst baut jetzt den ersten Realitätsanschluss.
Aber Herkunft ist noch kein Einzug.
Import ist noch kein Leben.
Console ist noch keine UI.
CameraModel ist noch kein Renderer.
OS Convergence ist noch keine fertige Plattform.
